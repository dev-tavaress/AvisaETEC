# Visão Geral do Projeto - AvisaETEC

## 1. Visão Geral
O AvisaETEC é um sistema web/mobile desenvolvido como Trabalho de Conclusão de Curso (TCC) para a ETEC. O objetivo é centralizar e automatizar a comunicação escolar em tempo real entre a instituição e os alunos.

=======================================================================

## 2. Atores e Perfis de Acesso
O acesso ao sistema será restrito por autenticação de login baseada em cargos, isto é, dividindo as permissões com base no papel autenticado de cada usuário:

1. **Administrador / Diretor:** Controle total e visão global dos módulos de envio.

2. **Coordenador / Professor:** Acesso restrito aos módulos permitidos para o envio de avisos oficiais. Podem direcionar as mensagens para:
   - Um aluno específico.
   - Uma turma inteira.

3. **Aluno:** Perfil exclusivo de leitura. Apenas visualizam as notificações recebidas, o mural e o calendário, sem permissão de envio.
